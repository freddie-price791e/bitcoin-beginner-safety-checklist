# Bitcoin Beginner Safety Checklist

A plain-English checklist for people who are learning how to buy, store, send, or sell Bitcoin for the first time.

This repository is educational only. It is not investment advice, not a trading system, and not a recommendation to buy Bitcoin.

## Before Buying

- Learn the basic terms first: BTC, wallet, address, exchange, seed phrase, private key, fee, and confirmation.
- Use only money you can afford to lose while learning.
- Read the platform's identity checks, limits, payment methods, and withdrawal rules.
- Check buy fees, spread, card fees, and withdrawal fees before clicking.
- Start with a tiny amount so you can learn the flow.

## Before Storing

- Know whether your BTC is on an exchange or in a self-custody wallet.
- Do not store seed phrases in screenshots, cloud notes, emails, or chat apps.
- Make an offline backup that you can read later.
- Practice restoring or verifying the backup before trusting it with meaningful funds.
- Understand that many wallet mistakes are not reversible.

## Before Sending

- Check the receiving address carefully.
- Check the network or withdrawal type if the platform shows one.
- Understand the fee and confirmation screen.
- Send a tiny test transaction before a larger transfer.
- Keep a record of the transaction ID and destination.

## Before Selling or Cashing Out

- Separate the words: selling, sending, withdrawing, and cashing out are not the same action.
- Selling changes BTC into fiat or another balance.
- Sending moves BTC to another Bitcoin address.
- Cashing out usually means selling first, then withdrawing fiat to a bank or payment method.
- Read payout limits, fees, and timing before you act.

This checklist is intentionally slow. For beginners, speed is not the goal. Understanding the action before clicking is the goal.
